# M1 และ M2: ตัวอย่างข้อมูลสำหรับทบทวนการเก็บข้อมูล

ข้อมูล CSV ในโฟลเดอร์นี้เป็น **ข้อมูลจำลองสำหรับสาธิตการวิเคราะห์**
ไม่ใช่ผลยืนยันจากการสำรวจหรือสัมภาษณ์บุคคลจริง

## แบบสอบถาม M1

[เปิด Google Form สำหรับเก็บคำตอบ](https://forms.gle/2JjwzDrbL9Thkqps6)

ฟอร์มมีข้อมูลพื้นฐาน 2 ข้อ และคำถามหลัก Q01–Q18 เป้าหมายผู้ตอบ 20 คน
คำตอบจริงจากฟอร์มต้องเก็บแยกจากข้อมูลจำลองใน PR นี้

## ไฟล์ที่แนบ

- [M1_summary.csv](M1_summary.csv): สรุปคำถามมาตราส่วน Q01–Q16
  แยก ALL/P1/P2/P3 รวม 64 แถว จากผู้ตอบจำลอง 20 คน
  (P1 = 7, P2 = 7, P3 = 6) ข้อ Q07 ใช้ฐาน 18 คนเพราะมีคำตอบไม่ประเมิน 2 ราย
- [M2_question_answers.csv](M2_question_answers.csv): คำถาม 5 ข้อต่อผู้ให้สัมภาษณ์จำลอง
  6 คน จาก 3 Persona กลุ่มละ 2 คน รวม 30 รายการ
  เป็นคนละ 1 ชุดคำถาม ไม่ใช่สัมภาษณ์คนเดิมซ้ำสองครั้ง

M2 เรียบเรียงตัวอย่างที่ผู้ใช้ส่งมา 1 ราย (INTSIM07) และแต่งคำตอบเพิ่มอีก 5 ราย
Persona และรหัส M1 เป็นการจัดเข้าชุดจำลอง ไม่ใช่การยืนยันตัวตนหรืออาชีพจริง
ข้อ M2-Q05 ของ INTSIM07 ยังไม่มีคำตอบในตัวอย่าง จึงไม่ตีความว่าไม่รู้จักเครื่องมือ

ไฟล์ใช้ UTF-8 BOM และรูปแบบ CSV คั่นด้วย comma เพื่อเปิดภาษาไทยใน Excel
จำนวนคนข้างต้นเป็นขอบเขตของชุดตัวอย่างนี้ ส่วนแผนเก็บข้อมูลใน SRS
ยังไม่ได้แก้ไขใน PR นี้
