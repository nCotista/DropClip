## 1. Objective & Scope

- [x] Stop the web companion from exposing clipboard history copied before a browser was linked.
- [x] Make "unlink" revoke the session token on the PC, not only in browser storage.
- [x] Fail a file transfer whose `finish` arrives with unverified or missing bytes.
- [x] Keep zero-byte files, malformed offers, resume offsets and live destination changes safe.
- [x] Recover half-open sockets on resume and use the protocol heartbeat timeouts.
- [x] Survive a corrupt `hosts.json` and a failed offline reconnect at startup.
- [x] Make the Windows installer transactional and fix tag-based app releases.

## 2. Technical Context & Key Decisions

- **Web privacy:** `WebSession.sinceClipId` is captured at claim time and `_state` filters with `c.id >= sinceClipId`, so the client cursor (`after`) cannot request pre-link history.
- **Unlink:** `POST /web/api/unlink` calls the existing `revoke`, removing the hashed token server-side; `web_page.dart` calls it before clearing `localStorage`. This closes the 8-hour window where a "removed" browser still had API access.
- **Transfer verifier:** `_Incoming.completed` records items whose SHA-256 matched and whose `.part` was renamed. `finish` returns `409 E_INCOMPLETE` and reports `failed` when any accepted item is not verified, rather than a false green "complete".
- **Per-transfer receiver:** `_Incoming` owns the `StreamingFileReceiver` created at accept time; a Settings destination change applies to the next offer and cannot split an in-flight transfer across folders.
- **Zero-byte files:** the sender now skips only when the receiver reports `state == "complete"`; an empty file's empty body still reaches `appendChunk`, which creates and verifies it.
- **Reconnect:** `PeerMesh.reach(force: true)` shuts down the stale session and clears backoff state before dialing, so mobile resume from doze does not trust a half-open socket. `drop()` now emits `peerChanges`.
- **Heartbeat:** `ControlPlaneSession` defaults use `ProtocolConstants.pingInterval` (15 s) and `pongTimeout` (45 s) instead of a 5 s false-positive timeout.
- **Startup durability:** `hosts.json` is written temp+rename; corrupt JSON is renamed to `.corrupt`; reconnect skips malformed entries; mobile `main()` starts offline instead of crashing.
- **Distribution:** the installer extracts to `DropClip.new`, validates `dropclip_desktop.exe`, renames the old install to `DropClip.old`, swaps, and restores the backup on failure. Release Apps runs on `v*` tags, checks out the requested tag and attaches assets to that release.
