## 2. Technical Context & Key Decisions (การตัดสินใจเชิงเทคนิค)
* **`DropClipColors` เป็น `ThemeExtension`** — widget อ่านผ่าน `DropClipColors.of(context)` และสลับตามธีม OS อัตโนมัติ (AC: Dark/Light ตาม OS)
* **ธีมสว่างไม่มีในดีไซน์** — derive เองให้ทุกสีตัวอักษรผ่าน 4.5:1 บนทุก surface (NFR-A01); ควรให้ `QA` ตรวจ
* **เทสต์ contrast เจอว่าดีไซน์ไม่ผ่าน:** ตัวอักษรขาวบน `#7C5CFF` (ปุ่มหลัก) ได้ 4.35:1 < 4.5 → ใช้ `#6E4EF5` (5.16:1) แทน ต้องแจ้ง `QA` ให้แก้ดีไซน์
* **ห้ามใช้ `google_fonts`** — โหลดฟอนต์จาก Google ตอน runtime ผิด Zero-Cloud ต้อง bundle เป็น asset; PR นี้ระบุชื่อ family + fallback ไว้ก่อน
* **ข้อสังเกตอื่นจากดีไซน์:** หน้า Clipboard แสดงพอร์ต `47470` แต่ spec กำหนด 53317–53417; หน้า PIN ระบุว่า PIN ไม่ถูกส่งผ่านเครือข่าย ✅ ตรงกับ Zero-PIN-on-Wire
* **`melos.yaml` เพิ่ม `repository:`** บรรทัดเดียวกับ T1.1 PR 1a (ไม่มีแล้ว Melos 6 รันไม่ได้)
* **ประวัติ clip เก็บแค่ใน memory** และหน้า UI แสดงแค่ *จำนวน* clip ที่ถูกระงับ ไม่แสดงเนื้อหา (NFR-S04); ข้อความเป็นแบบทั่วไปแทนชื่อ "1Password" ในดีไซน์ เพราะ marker บาง OS ไม่บอกชื่อแอป
* **เมนู Tray ทำเป็น Flutter widget** — ดีไซน์เป็น popover ที่มีสวิตช์และรายชื่อเครื่อง ซึ่งเมนู native ของ OS แสดงไม่ได้ จึงต้องเปิดเป็นหน้าต่าง popup ข้างไอคอน (PR ถัดไป)
* **ใช้ `tray_manager`/`window_manager` ^0.5.0 ไม่ใช่ 0.6+/0.8+** (lock ยังไม่ commit จึง resolve เป็น 0.5.3/0.5.2 — ตรวจแล้วทั้ง 0.5.0 และ 0.5.3/0.5.2) — รุ่นใหม่ย้ายไปใช้ `nativeapi` ที่มี build hook compile C++ ทุกครั้งที่ `flutter test` (เครื่องนี้ไม่มี compiler เทสต์ทั้งหมดพัง และ CI Ubuntu ต้องมี GTK dev) และยังไม่ส่ง event ปิดหน้าต่าง ซึ่ง close-to-tray ต้องใช้; 0.5.0 ใช้ platform channel ปกติ
* **ตรวจ plugin ก่อนใช้ (Zero-Cloud):** tray_manager, window_manager, menu_base, screen_retriever*, shortid, json_annotation — ไม่มี HTTP/socket/analytics/telemetry และไม่มี build hook
* **แยก `DesktopHost` (interface) กับ `TrayController` (logic)** — logic เทสต์ได้ด้วย fake; `NativeDesktopHost` เป็นชั้นบาง ๆ เปลี่ยน plugin ได้โดยไม่แตะ logic
* **ไอคอน tray เป็น placeholder** (โลโก้ Flutter จาก runner) — รอ `QA` ส่งไอคอนจริง (Windows .ico, macOS template PNG)
* **การรักษา Invariants:** ไม่มี network/cloud ใน UI package
