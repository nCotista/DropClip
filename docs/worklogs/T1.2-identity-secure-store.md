## Summary of Changes (Part 1: `feat/T1.2-device-identity`)
- Implemented `DeviceIdentity` (`E-01`, §4.1 & §15.2), `InMemorySecureKeyStore` (`§14.4`), and `DeviceIdentityManager` in `packages/dropclip_core/lib/src/security/device_identity.dart`.
- Auto-generates ECDSA P-256 (`prime256v1`) keypair and 10-year self-signed X.509 v3 cert (`CN=dropclip-<id>`), computes 64-char SHA-256 DER fingerprint, and separates `identity.json` from `dropclip.identity.p256` in `SecureKeyStore`.
- Added `signUtf8` / `verifyUtf8` (`ECDSA_P256_SHA256`) and automated disk audit test verifying zero plaintext private keys on disk (`NFR-S02`).

## Summary of Changes (Part 2: `feat/T1.2-trusted-device-store`)
- Implemented `TrustedDevice` (`E-02`, §15.3) and `TrustedDeviceStore` (`trusted_devices.json.enc`) using 256-bit master key (`dropclip.store.key`) and `nonce(12B) || ciphertext || tag(16B)` authenticated encryption.
- Added `fingerprintOf(deviceId)` (`TrustedFingerprintLookup` compatible), `isActiveFingerprint(fp)`, quarantine status transitions, and constant-time tag verification.
