## 2. Technical Context & Key Decisions (การตัดสินใจเชิงเทคนิค)
* **Disable macOS App Sandbox (`PR #111`, approved decision):** Set `com.apple.security.app-sandbox = false` in `DebugProfile.entitlements` and `Release.entitlements` for direct GitHub `.zip` distribution (`docs/05-RELEASE-AND-UPDATE-PLAN.md`), adding `ConfigStore.migrateMacSandboxData` so existing container settings/keys migrate cleanly and restoring `tray.show()` + `context.mounted` guard before `askToReceive`.
* **Node teardown safety (`PR #112`):** Rebased serialized `_revocationWork`, `_closed` guard, and awaiting pending revocations in `DesktopNode.close()` from `fix/windows-node-teardown` onto `main` while preserving `PeerMesh` teardown & `revocationSync` hardening.
* **Dual-stack mDNS IPv4 preference (`PR #113`, Desktop + Mobile):** `TlsTransportServer.bind` binds `InternetAddress.anyIPv4`, while dual-stack mDNS (`dns-sd`) frequently reports IPv6 records first and dialing peer IPv6 timed out on LAN. Added `packages/dropclip_core/lib/src/discovery/address_selector.dart` (`stripIpZone`, `peerAddressRank`, `selectBestPeerAddress`, `resolveMdnsPeerAddress`), updated `PeerCache` & `PeerMesh` (cap 6 candidates, never evict IPv4 for IPv6), updated Desktop & Mobile `BonsoirMdnsBackend`, and extended `_virtualAdapter` in `desktop_node.dart` to exclude macOS virtual/P2P interfaces (`awdl`, `llw`, `vmenet`, `feth`, `anpi`, `ipsec`, `bridge*`, `gif*`, `stf*`, `ap*`).
* **macOS Runner parity & `NSOpenPanel` (`PR #114`):** Set `visibleAtLaunch="NO"` in `MainMenu.xib` and `display: false` / `--hidden` check in `MainFlutterWindow.swift`; kept app alive in menu bar after closing the last window, added Dock reopen (`applicationShouldHandleReopen`), and added single-instance guard (`NSRunningApplication` + `DistributedNotificationCenter`, skipping `.xctest`) in `AppDelegate.swift`; replaced `/usr/bin/osascript` in `file_dialog.dart` with native `NSOpenPanel` on `dropclip/file_picker` (`FilePickerHandler.swift`, `FilePickerSupport.swift`).
