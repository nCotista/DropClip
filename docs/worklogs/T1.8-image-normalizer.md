## 1. Objective & Scope

- **PR 1a — `feat/T1.8-png-encoder`**

- **PR 1b — `feat/T1.8-dib-to-png`** (merge 1a เข้ามา)
  - [x] `decodeDib`: `CF_DIB`/`CF_DIBV5` (24/32 bpp, `BI_RGB`/`BI_BITFIELDS`) → RGBA ตาม §11.2 (BGR(A)→RGBA, กลับหัวเมื่อ `biHeight > 0`, alpha จาก `bV5AlphaMask`, ไม่มี alpha → 255)
- **ถัดไป:** PNG → `CF_DIBV5` สำหรับวางบน Windows (§11.2), macOS TIFF (ต้องใช้ Mac), ภาพทดสอบ 50 ภาพ SSIM ≥ 0.99

## 2. Key Decisions
* **PNG encoder เขียนเอง** ใช้แค่ `zlib` ของ `dart:io` + CRC32 — ไม่เพิ่ม package
* **Filter "Up" + zlib level 1:** วัด 4K (AOT) ได้ 124 ms (เป้า NFR-P05 < 200 ms) ไฟล์ 0.3 MiB; ถ้าไม่ใช้ filter ได้ 424 ms / 14.3 MiB (ภาพทดสอบเป็น gradient — ภาพหน้าจอจริงอาจต่างกัน)
* **Decode เร็วขึ้น 442 → 35 ms:** คำนวณ shift ของ mask ครั้งเดียวต่อภาพ + fast path สำหรับ BGRA ที่ Windows ใช้
* **32 bpp `BI_RGB` ที่ alpha เป็น 0 ทั้งภาพ → ทึบ** (หลายแอปไม่ใช้ byte นี้)
* **กัน decompression bomb (§11.3):** ตรวจ `IMAGE_MAX_PIXELS` ก่อนจองหน่วยความจำ; input ผิดรูปแบบ → `NormalizationException`
