## 2. Technical Context & Key Decisions (การตัดสินใจเชิงเทคนิค)

* **Packet ผิดรูปแบบ → `tryParse` คืน `null`** แทน throw เพื่อให้ caller ทิ้งแบบเงียบได้ (§3.3) — ตรวจ `v`, `min_v ≤ v`, `id` เป็น UUID v4, `os` ∈ 4 ค่า, `tier` ต้องตรงกับ `os` (§2.2), `port` อยู่ในช่วง 53317–53417, `fp` เป็น hex 64 ตัว, `name` เป็น Base64 ของ UTF-8 ที่ถูกต้อง และไม่เกิน 64 bytes
* **`tier` derive จาก `os`** (`DeviceOs.tier`) ฝั่งส่งจึงประกาศค่าที่ไม่ตรงกับ os ไม่ได้
* **ตัดชื่อเครื่องที่ขอบ code point** (`truncateName`) เพื่อไม่ให้ Emoji/ภาษาไทยถูกตัดครึ่งตัว
* **เวลาส่งเข้ามาจากภายนอก (`now`)** และเรียก `sweep()` เป็นรอบ ๆ ทำให้ทดสอบ timeout 30s/120s ได้โดยไม่ต้องรอจริง
* **Trust Store ส่งเข้ามาเป็นฟังก์ชัน `TrustedFingerprintLookup`** เพราะ T1.2 (`LEAD`) ยังไม่เสร็จ — ไม่ผูกกับรูปแบบ storage
* **Peer ที่ `connected` ไม่ถูกทำ stale และไม่ถูกลบด้วย goodbye** — WS heartbeat เป็นตัวตัดสิน (§3.5) ตอน `markDisconnected` จะเริ่มนับ `lastSeen` ใหม่
* **TXT `port` ≠ SRV port → ทิ้ง** (§3.2 กำหนดว่าสองค่านี้ MUST เท่ากัน)
* **การรักษา Invariants:** TXT มีแต่ข้อมูลสาธารณะ ไม่มี key/nonce/PIN; ไม่มี cloud
