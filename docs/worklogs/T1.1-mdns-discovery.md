## 2. Technical Context & Key Decisions (การตัดสินใจเชิงเทคนิค)

* **Packet ผิดรูปแบบ → `tryParse` คืน `null`** แทน throw เพื่อให้ caller ทิ้งแบบเงียบได้ (§3.3) — ตรวจ `v`, `min_v ≤ v`, `id` เป็น UUID v4, `os` ∈ 4 ค่า, `tier` ต้องตรงกับ `os` (§2.2), `port` อยู่ในช่วง 53317–53417, `fp` เป็น hex 64 ตัว, `name` เป็น Base64 ของ UTF-8 ที่ถูกต้อง และไม่เกิน 64 bytes
* **`tier` derive จาก `os`** (`DeviceOs.tier`) ฝั่งส่งจึงประกาศค่าที่ไม่ตรงกับ os ไม่ได้
* **ตัดชื่อเครื่องที่ขอบ code point** (`truncateName`) เพื่อไม่ให้ Emoji/ภาษาไทยถูกตัดครึ่งตัว
* **เวลาส่งเข้ามาจากภายนอก (`now`)** และเรียก `sweep()` เป็นรอบ ๆ ทำให้ทดสอบ timeout 30s/120s ได้โดยไม่ต้องรอจริง
* **Trust Store ส่งเข้ามาเป็นฟังก์ชัน `TrustedFingerprintLookup`** เพราะ T1.2 (`LEAD`) ยังไม่เสร็จ — ไม่ผูกกับรูปแบบ storage
* **Peer ที่ `connected` ไม่ถูกทำ stale และไม่ถูกลบด้วย goodbye** — WS heartbeat เป็นตัวตัดสิน (§3.5) ตอน `markDisconnected` จะเริ่มนับ `lastSeen` ใหม่
* **TXT `port` ≠ SRV port → ทิ้ง** (§3.2 กำหนดว่าสองค่านี้ MUST เท่ากัน)
* **`DiscoveryService` เป็น pure Dart** — `bonsoir` เป็น Flutter plugin ใส่ใน `dropclip_core` ไม่ได้ จึงแยก interface `MdnsBackend` และทดสอบด้วย fake backend
* **เทสต์ `stop()` รันแบบเวลาจริง** — future จาก `cancel()` ของ broadcast subscription จบใน root zone ที่ `FakeAsync` flush ไม่ได้
* **bonsoir รายงาน service ครั้งเดียว** — `query()` จึง resolve ทุก service ที่รู้จักซ้ำทุก 10 s เพื่อให้ `last_seen_at` สด (§3.3) ไม่งั้นทุกเครื่องจะ stale หลัง 30 s
* **Windows รายงาน service ซ้ำทุก adapter** — `DiscoveryController` ส่งให้ UI เฉพาะเมื่อรายการที่แสดงเปลี่ยนจริง
* **Identity ชั่วคราว (รอ T1.2/T1.4):** device id สุ่มใหม่ทุกครั้งที่เปิด, `fp` สุ่ม (ไม่ใช่ fingerprint ของ cert จริง), port 53317 (ยังไม่มี server ฟัง); ทุกเครื่องเป็น "ready to pair" เพราะยังไม่มี Trusted Store
* **Address ที่ได้บนเครื่องเดียวกันคือ 192.168.56.1 (VirtualBox host-only)** — Windows ตอบด้วย address ของ adapter ที่รับ query; ข้ามเครื่องผ่าน Wi-Fi น่าจะได้ IP ของ Wi-Fi แต่ยังไม่ได้ยืนยัน; T1.4 ควรลองทุก address
* **ตรวจ plugin ก่อนใช้:** bonsoir 7.1.6 + platform packages + args/dbus/petitparser/xml/ffi — ไม่มี HTTP/socket/telemetry (เจอแค่ใน example ของ `xml` ที่ไม่ถูก compile), ไม่มี build hook
* **Dev aid:** `DROPCLIP_DISCOVERY_LOG=<file>` เขียน event discovery ลงไฟล์ (TXT เป็นข้อมูลสาธารณะ)
* **การรักษา Invariants:** TXT มีแต่ข้อมูลสาธารณะ ไม่มี key/nonce/PIN; ไม่มี cloud
