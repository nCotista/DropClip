## 2. Technical Context & Key Decisions (การตัดสินใจเชิงเทคนิค)
* **เลือก T1.7 ก่อน T1.4:** T1.4 ขึ้นกับ T1.2 ซึ่งยัง `READY FOR PR` ไม่ได้ merge (DoR §3.1); T1.7 ขึ้นกับ T0.1 เท่านั้น และ T1.8/T1.9 ของ DESK รออยู่
* **แยก logic ออกจาก Win32 (`ClipboardApi`):** ทำให้เทสต์ C++ ด้วย fake บน Linux CI ได้ (g++ `-Wall -Wextra -Werror`) และตรวจได้ว่า "ไม่อ่านเนื้อหาเมื่อ concealed" ได้จริง
* **Fail closed (§10.4):** มี marker history/cloud แต่เปิด clipboard ไม่ได้ → ถือเป็น concealed; Dart ฝั่ง `ClipSnapshot` ก็ทิ้ง `items` อีกชั้นถ้า `is_concealed: true` (กัน native bug)
* **Native ไม่แปลงรูป (§14.1):** ส่ง `image/png` / `image/x-win-dibv5` / `image/x-win-dib` ให้ Dart normalizer (T1.8) แปลง
* **Dart package ไม่พึ่ง Flutter:** `ClipboardChannel` เป็น interface ให้ desktop app ห่อ `MethodChannel`/`EventChannel` เอง
* **แบ่ง PR ตามกฎ 400 บรรทัด:** PR 1 (632) → 1a + 1b; PR 2 (~480) → 2a + 2b
* **Invariants:** ไม่ log เนื้อหา clipboard (log แค่ชื่อ event), ไม่มี `readAsBytes()`, ไม่มี network/crypto ใน ticket นี้
