## 2. Technical Context & Key Decisions (การตัดสินใจเชิงเทคนิค)
* **Defense-in-Depth Pinning (§4.4 & ADR-006):** ตรวจสอบ SHA-256 DER Fingerprint ของ `req.certificate` ซ้ำที่ระดับ Application Layer ทุกคำขอ เพื่อให้การเพิกถอนสิทธิ์มีผลทันที (`< 1s`) และสร้างกุญแจทดสอบแบบ Ephemeral ใน `Directory.systemTemp`
